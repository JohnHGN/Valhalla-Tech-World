# راهنمای اتصال | Valhalla Tech World

راهنمای فارسی و راست‌چین V2Ray و WireGuard به‌همراه خدمات و آموزش‌های کامپیوتر مجموعه.

## سایت زنده

[مشاهدهٔ سایت](https://johnhgn.github.io/valhalla-tech-world-guide/)

## اجرا در کامپیوتر

فایل index.html را باز کنید؛ یا در پوشهٔ پروژه این دستور را اجرا کنید:

```sh
python3 -m http.server 8000
```

سپس به [http://localhost:8000](http://localhost:8000) بروید.

## انتشار

مخزن [JohnHGN/valhalla-tech-world-guide](https://github.com/JohnHGN/valhalla-tech-world-guide) عمومی است. گردش‌کار .github/workflows/deploy-pages.yml با هر push به شاخهٔ main فایل‌های استاتیک را خودکار روی GitHub Pages منتشر می‌کند.

## ساختار فایل‌ها

- index.html: ساختار و محتوای صفحه
- styles.css: طراحی واکنش‌گرا و راست‌چین
- script.js: انتخاب سرویس و دستگاه، راهنمای مراحل، فیلتر آموزش‌ها و جست‌وجو
- assets/: لوگو و تصویر شفق و کوهستان

## فونت‌ها و محتوا

تیتر فارسی Homa و متن فارسی Yas در اولویت‌اند؛ تیتر انگلیسی از Orbitron و متن انگلیسی از Arial Rounded استفاده می‌کند. فایل‌های وب Homa و Yas در این پروژه نیستند، بنابراین مرورگر در نبود قلم نصب‌شده از Amiri/Vazirmatn و Nunito استفاده می‌کند. برای افزودن نسخهٔ دقیق وب، فایل‌های مجاز WOFF2 را اضافه کنید.

آموزش‌ها و خدمات از اطلاعات عمومی کانال مجموعه انتخاب شده‌اند. لینک اشتراک، آدرس سرور، رمز یا مشخصات ساختگی در سایت قرار ندارد.
