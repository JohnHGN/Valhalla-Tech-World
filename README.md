# راهنمای اتصال | Valhalla Tech World

یک وب‌سایت استاتیک، فارسی و راست‌چین برای راهنمای اتصال و معرفی خدمات و آموزش‌های Valhalla Tech World. پروژه به فریم‌ورک یا مرحلهٔ ساخت نیاز ندارد؛ قلم‌های جایگزین با اتصال اینترنت از Google Fonts بارگیری می‌شوند.

## اجرا در کامپیوتر

1. پوشهٔ پروژه را باز کنید.
2. فایل `index.html` را در مرورگر باز کنید.

برای پیش‌نمایش از یک وب‌سرور محلی نیز می‌توانید در همین پوشه اجرا کنید:

```sh
python3 -m http.server 8000
```

سپس در مرورگر به `http://localhost:8000` بروید.

## انتشار

سایت روی GitHub Pages منتشر شده است: [مشاهدهٔ سایت](https://johnhgn.github.io/valhalla-tech-world-guide/). نیازی به build command نیست؛ گردش‌کار زیر انتشار را خودکار می‌کند.

مخزن عمومی: [JohnHGN/valhalla-tech-world-guide](https://github.com/JohnHGN/valhalla-tech-world-guide). فایل `.github/workflows/deploy-pages.yml` با هر push به شاخهٔ `main` سایت را مجدداً منتشر می‌کند.

## فایل‌ها

- `index.html` ساختار و متن فارسی
- `styles.css` ظاهر واکنش‌گرا و راست‌چین
- `script.js` جابه‌جایی میان صفحهٔ اصلی و تب راهنمای VPN، انتخاب سرویس و دستگاه، فیلتر مقالات و جست‌وجوی سریع
- `assets/aurora-mountains.jpg` تصویر پس‌زمینهٔ شفق و کوهستان
- `assets/valhalla-logo.jpg` لوگوی مجموعه که در سربرگ و پابرگ استفاده شده است

## یادداشت برند و محتوا

لوگو در سربرگ و پابرگ به کار رفته است. رنگ‌های شفقی و یخی، قاب‌های زاویه‌دار، نورهای سرخ و فیروزه‌ای و قلم Orbitron حال‌وهوای فناوری و گیمینگ را کنار تم نورس نگه می‌دارند. صفحه برای موبایل، تبلت و دسکتاپ واکنش‌گراست و راهنمای اتصال Android، iOS، Windows و macOS دارد.

قلم فارسی `B Nazanin / Nazanin` برای تیترها و متن در اولویت است؛ اگر روی دستگاه بازدیدکننده نصب نباشد، مرورگر از Amiri یا Vazirmatn استفاده می‌کند. تیتر انگلیسی از `Orbitron` و متن انگلیسی از خانوادهٔ `Arial Rounded` استفاده می‌کند. فایل وب نازنین داخل پروژه قرار نگرفته است؛ برای نمایش یکسان نازنین روی همهٔ دستگاه‌ها، فایل وب دارای مجوز (`.woff2`) لازم است.

نوار جست‌وجوی سربرگ در متن خدمات، مراحل اتصال، آموزش‌ها و پرسش‌های پرتکرار جست‌وجو می‌کند و با انتخاب هر نتیجه به بخش مربوط می‌رود.

راهنمای V2Ray و WireGuard در تب جداگانهٔ «راهنمای اتصال به VPN» آمده و مراحل انتخاب سرویس، دستگاه و راه‌اندازی را یک‌جا نمایش می‌دهد. بخش «مقالات» از پست‌های آموزشی کانال پیوند می‌گیرد و «پادکست‌ها» پست صوتی قسمت اول پرامپت‌نویسی با ChatGPT را از [پست شمارهٔ ۶۴](https://t.me/valhala_tw/64) در خود صفحه نمایش می‌دهد. رابط کاربری شامل حرکت‌های ظریف هنگام ورود، پیمایش و تعامل است و تنظیم سیستم برای کاهش حرکت را رعایت می‌کند.

بخش خدمات، شمارهٔ مجازی، Apple ID و آموزش‌ها از معرفی عمومی کانال و پست‌هایش ساخته شده‌اند. آموزش‌ها با دسته‌های ویندوز، سخت‌افزار، شبکه و هوش مصنوعی فیلتر می‌شوند و هر کارت به پست منبع در کانال پیوند دارد. جزئیات پلن‌های اتصال، بات و Apple ID نیز به پست‌های مربوط متصل شده‌اند. قیمت یا موجودی‌ای که در کانال مشخص نشده وارد نشده است. [کانال تلگرام](https://t.me/valhala_tw)

هیچ لینک اشتراک، فایل کانفیگ، آدرس سرور، نام کاربری یا رمز ساختگی در سایت قرار داده نشده است. کاربر باید اطلاعات سرویس خودش را از پیام یا پنل اصلی دریافت کند. لینک‌های دریافت برنامه به صفحهٔ رسمی WireGuard، Hiddify و مخزن‌های رسمی v2rayNG/v2rayN اشاره می‌کنند.
