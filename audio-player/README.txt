VALHALLA PLAYER UPDATE

1. Replace your site's index.html and player.css with these updated files.
2. player.js is included unchanged; replace it only if you want to keep the
   three player files together.
3. Keep your existing assets/audio, player skin, podcast covers, playlist.js,
   and all other project assets.

YAS FONT:
The CSS loads Yas from assets/fonts/Yas.woff2 (with .woff and .ttf fallbacks).
Add your Yas font file to that exact path in the repository. If its filename
differs, edit the @font-face URL in player.css to match the actual file.
