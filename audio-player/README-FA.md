# Valhalla Audio Player — نسخه اکولایزر و فهرست پخش

## نصب و اجرا
کل پوشه را با همان ساختار روی هاست قرار دهید. تصویر پایه در `assets/valhalla-player-base.png` قرار دارد. بهتر است صفحه از طریق وب‌سرور اجرا شود.

## افزودن آهنگ‌ها
فایل‌های MP3 را در `assets/tracks/` قرار دهید. سپس فایل `playlist.js` را ویرایش کنید و مسیرها و عنوان‌ها را مطابق فایل‌های واقعی بنویسید. پنج مسیر نمونه در آن تعریف شده است:
`track-01.mp3` تا `track-05.mp3`.

نمونه:
```js
window.ValhallaPlaylist = [
  { title: "نام آهنگ اول", src: "assets/tracks/song-a.mp3" },
  { title: "نام آهنگ دوم", src: "assets/tracks/song-b.mp3" }
];
window.ValhallaPlayer?.setPlaylist(window.ValhallaPlaylist);
```

## امکانات
- اکولایزر زنده مبتنی بر Web Audio API و واکنش‌گرا با صدای واقعی آهنگ
- فهرست پخش چندقطعه‌ای با قبلی/بعدی و رفتن خودکار به قطعه بعدی
- پخش/توقف، نوار زمان، عقب ۱۵ و جلو ۳۰ ثانیه
- سرعت 0.5x تا 2x، کنترل صدا، تکرار، توقف خودکار و اشتراک‌گذاری

**توجه:** فایل‌های MP3 در این بسته نیستند. مسیرهای نمونه تا زمانی که فایل‌های واقعی را در پوشه tracks قرار ندهید، قابل پخش نخواهند بود.
